Apparatus & model guide

A real simple pendulum uses a small dense bob suspended by a light, inextensible string.

LAB
GUIDE

Apparatus required

  1. 01Retort stand with heavy base
  2. 02Clamp / split cork to hold the string
  3. 03Light, inextensible thread
  4. 04Spherical metallic bob
  5. 05Metre scale — measures effective length
  6. 06Stopwatch — times a set of oscillations
  7. 07Set square / pointer for length measurement

Label key

Rigid supportKeeps the point of suspension fixed
Point of suspensionPivot about which the bob oscillates
String (length L)Measured from pivot to the bob's centre
BobCompact mass treated as a point mass
Mean positionVertical equilibrium position
AmplitudeMaximum angular displacement
KEY RELATIONT = 2π√(L/g) • g = 4π²L/T²

Accuracy note The period formula is the small-angle approximation. Measure several oscillations and divide total time by their number.
